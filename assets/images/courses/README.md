# صور الدورات

عشان تضيفي صورة لأي دورة بقسم "دورات" بالصفحة الرئيسية، بس ارفعي الملف هنا بجيتهب (Add file → Upload files) بنفس الاسم بالضبط — الصورة تظهر بالموقع تلقائيًا بدون أي تعديل على الكود.

| اسم الملف | الدورة |
|---|---|
| `course-1.jpg` | دورات المراكز الصيفية |
| `course-2.jpg` | دورات المؤسسات الأكاديمية |
| `course-3.jpg` | دورات طلبة المدارس والمبتعثين |
| `course-4.jpg` | دورات الجهات الحكومية والخاصة |
| `course-5.jpg` | دورات الفئة العامة |
| `course-6.jpg` | دورات خارجية |

يفضّل صورة بنسبة عرض إلى ارتفاع 4:3 (مثلاً 800×600) عشان تناسب الإطار بدون قص كبير. أي دورة ما فيها صورة بعد تظهر بأيقونة 📷 بدل الصورة تلقائيًا.
